# প্রজেক্ট আইডিয়া

কম্পোনেন্ট আলাদা আলাদা শেখার পর এগুলো জুড়ে বাস্তব প্রজেক্ট বানানো হয়। প্রতিটি প্রজেক্টের কোড থাকবে `src/projects/<প্রজেক্টের_নাম>/` এ।

প্রজেক্ট শুরুর আগে `components.md` এ দেখুন কোন কোন কম্পোনেন্ট আগে প্র্যাকটিস করা দরকার।

---

## প্রজেক্ট ১: স্মার্ট ওয়াটার ট্যাংক ও পাম্প (উদাহরণ)

**লক্ষ্য:** ট্যাংকের পানির লেভেল মাপা, লেভেল কমে গেলে পাম্প নিজে চালু হওয়া, ভরে গেলে বন্ধ হওয়া। মোবাইল অ্যাপ থেকে লেভেল দেখা ও পাম্প অন/অফ করা।

### সিস্টেম কেমন হবে

```
[আল্ট্রাসনিক সেন্সর] ──┐
                        ├── [ESP32] ──Wi-Fi──> [সার্ভার] <──> [মোবাইল অ্যাপ]
[রিলে] ── [পানির পাম্প] ─┘
```

| অংশ | কাজ |
|---|---|
| ESP32 | সেন্সর পড়ে, পাম্প কন্ট্রোল করে, সার্ভারে ডেটা পাঠায় |
| আল্ট্রাসনিক HC-SR04 | ট্যাংকে পানির দূরত্ব মাপে, সেখান থেকে লেভেল (%) বের হয় |
| রিলে মডিউল | ESP32 এর সংকেতে পাম্প চালু বা বন্ধ করে |
| পাম্প | পানি তোলে (সুরক্ষার জন্য নিচের নোট দেখুন) |
| সার্ভার | ডেটা জমা রাখে, মোবাইল অ্যাপ ও ESP32 এর মাঝে যোগাযোগ করে |
| মোবাইল অ্যাপ | লেভেল দেখায়, পাম্প অন/অফ বাটন দেয় |

### দরকারি পূর্বশর্ত (components.md থেকে)

- [ ] LED ও রিলে মডিউল
- [ ] আল্ট্রাসনিক HC-SR04
- [ ] Wi-Fi কানেক্ট
- [ ] HTTP API কল বা MQTT

### ধাপে ধাপে কাজ

1. **ধাপ ১ — সেন্সর:** HC-SR04 দিয়ে দূরত্ব পড়ে সিরিয়ালে ছাপানো।
2. **ধাপ ২ — লেভেল হিসাব:** দূরত্ব থেকে ট্যাংক লেভেল (%) বের করা।
3. **ধাপ ৩ — পাম্প কন্ট্রোল:** রিলে দিয়ে LED বা ছোট পাম্প অন/অফ করা।
4. **ধাপ ৪ — অটো লজিক:** লেভেল ২০% এর নিচে হলে পাম্প অন, ৯০% এ অফ (hysteresis, যাতে বারবার অন-অফ না হয়)।
5. **ধাপ ৫ — Wi-Fi:** ESP32 কে Wi-Fi তে কানেক্ট করা।
6. **ধাপ ৬ — সার্ভার:** ছোট সার্ভার বানানো (যেমন Python FastAPI বা Node.js)। ESP32 লেভেল পাঠাবে, সার্ভার জমা রাখবে।
7. **ধাপ ৭ — কমান্ড:** সার্ভার থেকে পাম্প অন/অফ কমান্ড ESP32 তে পাঠানো।
8. **ধাপ ৮ — মোবাইল অ্যাপ:** লেভেল দেখানো ও বাটন (Flutter বা React Native)।
9. **ধাপ ৯ — নিরাপত্তা:** টাইমআউট (পাম্প সর্বোচ্চ কত মিনিট চলবে), শুকনো চালানো রোধ, API তে পাসওয়ার্ড বা টোকেন।

### সুরক্ষা নোট

- ২২০V এসি পাম্পে সরাসরি কাজ করবেন না। শুরুতে ৫V বা ১২V ছোট ডিসি পাম্প দিয়ে প্র্যাকটিস করুন।
- রিলে ও পাম্পের পাওয়ার সাপ্লাই ESP32 থেকে আলাদা রাখুন, মাটি (GND) এক করুন।
- পানি ও বিদ্যুৎ আলাদা রাখুন, সার্কিট ওয়াটারপ্রুফ বক্সে রাখুন।
- এসি লাইনে কাজ করতে হলে অভিজ্ঞ ইলেকট্রিশিয়ানের সাহায্য নিন।

## আরও প্রজেক্ট আইডিয়া

| প্রজেক্ট | কম্পোনেন্ট | কী শিখবেন |
|---|---|---|
| স্মার্ট হোম লাইট | রিলে, বাটন, Wi-Fi | ফোন থেকে বাতি অন/অফ, ওয়েব সার্ভার |
| আবহাওয়া স্টেশন | DHT22, OLED, MQTT | সেন্সর ডেটা ড্যাশবোর্ডে দেখানো |
| অটো গাছে পানি | সয়েল মইশ্চার, পাম্প, রিলে | সেন্সর-ভিত্তিক অটোমেশন |
| রিমোট কন্ট্রোল রোবট গাড়ি | DC মোটর, L298N, Wi-Fi | মোবাইল থেকে গাড়ি চালানো |
| লাইন ফলোয়ার রোবট | IR সেন্সর, মোটর | কন্ট্রোল লুপ, সেন্সর ফিডব্যাক |
| অবস্টাকল এভোডিং রোবট | আল্ট্রাসনিক, সার্ভো, মোটর | সিদ্ধান্ত নেওয়ার লজিক |
| স্মার্ট ডোর লক | সার্ভো, কীপ্যাড, বাজার | নিরাপত্তা, অ্যাক্সেস কন্ট্রোল |
| ঘরের নিরাপত্তা সিস্টেম | PIR, বাজার, নোটিফিকেশন | মুভমেন্ট ডিটেকশন, অ্যালার্ট |
| GPS ট্র্যাকার | GPS মডিউল, সার্ভার, ম্যাপ | লোকেশন ডেটা পাঠানো ও ম্যাপে দেখানো |
| রোবট আর্ম | সার্ভো ×৪–৬ | মোশন কন্ট্রোল |
