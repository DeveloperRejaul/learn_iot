# Day 1 — ESP32 প্রথম পরিচয়

তারিখ: 2026-11-16

## আজকের লক্ষ্য

ESP32 বোর্ড USB দিয়ে কানেক্ট করে MicroPython এ LED জ্বালানো-নেভানো (blink) প্রোগ্রাম চালানো।

## আজ যা করা হয়েছে

- ESP32 USB তে কানেক্ট করা হয়েছে, পোর্ট শনাক্ত হয়েছে: `/dev/cu.usbserial-59450705951`
- `esptool chip-id` দিয়ে চিপ শনাক্ত হয়েছে
- `pipenv` দিয়ে প্যাকেজ ম্যানেজমেন্ট শুরু: `esptool` 5.6.0, `mpremote` 1.29.0, dev হিসেবে `micropython-esp32-stubs` 1.29.0.post1
- `Pipfile` ও `Pipfile.lock` এ সব ভার্সন লক করা হয়েছে (Python 3.15)
- LED blink কোড লেখা হয়েছে: `src/day_01/main.py`
- Wokwi সিমুলেটরে (ওয়েব) LED blink সফলভাবে চালানো হয়েছে
- VS Code এর জন্য Wokwi সিমুলেটর ফাইল তৈরি: `simulator/esp32/` (`wokwi.toml`, `diagram.json`, MicroPython v1.29.0 ফার্মওয়্যার)
- VS Code এ Wokwi সিমুলেটরে LED blink সফলভাবে চলেছে (`mpremote ... run src/day_01/main.py` দিয়ে)
- `docs/components.md` (কম্পোনেন্ট তালিকা) ও `docs/projects.md` (প্রজেক্ট আইডিয়া) লেখা হয়েছে
- `src/` দিনভিত্তিক ফোল্ডারে সাজানো হয়েছে, কোড GitHub এ push করা হয়েছে
- `README.md` ও এই ডক লেখা হয়েছে

## বোর্ডের তথ্য

| বিষয় | মান |
|---|---|
| চিপ | ESP32-D0WD-V3 (revision v3.1) |
| ফিচার | Wi-Fi, Bluetooth, Dual Core, 240MHz |
| Crystal | 40MHz |
| MAC | 5c:01:3b:4a:34:28 |
| USB পোর্ট | `/dev/cu.usbserial-59450705951` |
| অন-বোর্ড LED | GPIO 2 (বোর্ডভেদে আলাদা হতে পারে) |

## আজ যা শিখলাম

- **MicroPython কী:** ESP32 এর মতো ছোট চিপে চলা Python। বোর্ডে আলাদা করে ফার্মওয়্যার ফ্ল্যাশ করতে হয়।
- **pipenv:** `Pipfile` এ দরকারি প্যাকেজ লেখা থাকে, `Pipfile.lock` এ প্রতিটি প্যাকেজের সঠিক ভার্সন লক হয়। ফলে অন্য কম্পিউটারে `pipenv install --dev` চালালে হুবহু একই ভার্সন ইনস্টল হয়।
- **esptool:** বোর্ডের ফ্ল্যাশ মেমোরিতে ফার্মওয়্যার লেখা, মোছা ও চিপের তথ্য দেখার টুল।
- **mpremote:** বোর্ডে কোড চালানো, ফাইল কপি করা ও রিসেট করার টুল।
- **`machine` মডিউল:** MicroPython এর নিজস্ব মডিউল। Mac এ নেই বলে VS Code এ Pylance ওয়ার্নিং দেখায়। এটা আসল এরর নয়। stubs ইনস্টল করলে বা `# type: ignore` দিলে যায়।
- **GPIO:** চিপের পিন। `Pin(2, Pin.OUT)` মানে GPIO 2 কে আউটপুট হিসেবে ব্যবহার করা। পিন দুই অবস্থায় থাকে: `1` (HIGH, প্রায় 3.3V) ও `0` (LOW, 0V)।
- **LED সার্কিট:** `GPIO 2 → 220Ω রেজিস্টর → LED এর anode (বাঁকা, লম্বা পা)`, আর `LED এর cathode (সোজা পা) → GND`। রেজিস্টর কারেন্ট সীমিত রাখে, নইলে LED বা পিন পুড়ে যেতে পারে। LED শুধু এক দিকে কারেন্ট যেতে দেয়।
- **পিন লেবেল বনাম GPIO নম্বর:** বোর্ডে ছাপা লেবেল সবসময় GPIO নম্বর নয়। বাঁ পাশের `D2` আসলে GPIO 9। GPIO 6 থেকে 11 ফ্ল্যাশ মেমোরির পিন, ব্যবহার করবেন না। GPIO 34, 35, 36, 39 শুধু ইনপুট।
- **`print()` দিয়ে ডিবাগ:** কোড চলছে কি না বোঝার সহজ উপায়। কনসোলে লেখা এলে কোড ঠিক, তখন সমস্যা তারে।
- **সিমুলেটর (Wokwi):** আসল বোর্ড ছাড়াই ESP32 ও কম্পোনেন্ট পরীক্ষা করা যায়। তার ভুল করলে কিছু পোড়ে না। আসল পাওয়ার, মোটর কারেন্ট বা পানির মতো বিষয় সিমুলেটরে পুরোপুরি মেলে না।

## কোড

`src/day_01/main.py`:

```python
from machine import Pin  # type: ignore
import time

led = Pin(2, Pin.OUT)

while True:
    led.value(1)   # LED জ্বলবে
    time.sleep(1)
    led.value(0)   # LED নিভবে
    time.sleep(1)
```

## সমস্যা ও পর্যবেক্ষণ

- `mpremote` চালাতে গেলে `could not enter raw repl` এরর এসেছে। কারণ বোর্ডে এখনো MicroPython ফার্মওয়্যার ফ্ল্যাশ করা হয়নি।
- Pylance এ `Import "machine" could not be resolved` ওয়ার্নিং এসেছে। সমাধান README তে আছে।
- Wokwi তে কোড চলেছিল (কনসোলে `LED ON করা হয়েছে` এসেছিল) কিন্তু LED জ্বলেনি। কারণ তার লাগানো ছিল বাঁ পাশের `D2` পিনে, যা আসলে GPIO 9। কোডে ছিল GPIO 2। ডান পাশের `2` লেখা পিনে তার নিতেই LED জ্বলেছে।
- VS Code সিমুলেটরে `fs cp` দিয়ে `main.py` আপলোড করার পর সিমুলেশন রিস্টার্ট করায় ফাইল মুছে গিয়েছিল (`Performing initial setup`, কনসোলে শুধু `>>>`)। সিমুলেটরের ফ্ল্যাশ রিস্টার্টে নতুন হয়। সমাধান: `mpremote ... run src/day_01/main.py` দিয়ে কোড সরাসরি চালানো।
- `fs cp` এর সময় `OSError: [Errno 2] ENOENT` স্বাভাবিক, ওটা এরর নয়।
- শিক্ষা: কোড আর তারের পিন নম্বর মিলছে কি না যাচাই করুন। বুট লগে `entry 0x...` পর্যন্ত আসা স্বাভাবিক, ওটা এরর নয়।
